# 躁鬱睡眠記録

躁鬱睡眠カレンダーを元にした、睡眠と気分の記録アプリ。HTML / CSS / JavaScriptのみで動作し、外部へのデータ送信はありません。

## 使い方

`index.html` をブラウザで開くか、`python3 -m http.server 8000` で静的サーバーを起動します。HTTPSの静的ホスティングではPWAとして利用できます。

- ヘッダーの＋から起床・就寝の日時を記録。起床・就寝のどちらもメモを保存でき、就寝時は気分を5段階から選べます。
- ナビゲーションからカレンダー・グラフ・タイムラインを切り替えられます。初期画面はカレンダーです。カレンダーは日曜始まりで、各日の起床・就寝の全記録を時刻の昇順で表示します。就寝時の気分と各記録のメモも表示します。記録を押すと編集、日付を押すと追加できます。カレンダーとグラフの表示月は共通です。
- グラフは月ごとの0〜24時表示。日付をまたぐ睡眠・覚醒区間を分割して描きます。睡眠の帯には就寝から起床まで、覚醒の帯には起床から就寝までの合計時間を表示します。就寝・起床時刻の縦の太線やタイムラインの記録をタップすると編集・削除できます。帯自体はクリックしても編集画面を開きません。日付をまたぐ分割位置には太線を表示せず、実際の記録時刻に表示します。
- 就寝→起床を睡眠、起床→就寝を覚醒とし、睡眠区間には起床時のメモ、覚醒区間には就寝時の気分・メモを表示します。連続する同じ種類の記録の間、最初の記録以前、最後の記録以降は推測せず空白になります。
- タイムラインでは日付で区切らず、新しい順に並べます。経過時間は直前の反対の種類の記録から計算します。
- JSONエクスポートはversion 2。目標起床時刻・目標就寝時刻もsettings（wake・bed）に含めます。インポートは同じIDを上書きし、他の記録を保持します。目標時刻が含まれる場合は設定も上書きし、含まれない従来のJSONでは現在の設定を保持します。同じ日時の重複や不正な目標時刻は拒否します。
- 旧カレンダーのversion 1のJSONもインポートできます。起床・就寝・昼寝の各時刻を、イベントに変換します。午前（00:00〜11:59）の通常就寝は翌日、起床・昼寝は元の日付とします。コメントは通常就寝だけに、通常就寝がなければ昼寝開始だけに付けます。元データの時刻なし気分／メモや不正日時は、欠落を防ぐためファイル全体を拒否して通知します。旧アプリは不正日時を許容するため、必要なら元の記録を修正してください。

日時は端末のローカル時刻で扱います。記録はこのアプリ専用のlocalStorageに保存します。自動同期はありません。ブラウザデータの削除で失われるため、定期的にJSONをバックアップしてください。読み込みや保存に失敗した場合は画面に通知します。

## 確認

`node --test model.test.cjs`

`node --test app.test.cjs`（カレンダーの複数記録・時刻順・月境界・編集・追加・画面切り替え）

サービスワーカー更新時は `sw.js` の VERSION を変更します。入力中の強制更新は行わず、すべてのアプリタブを閉じて再度開くと新バージョンが有効になります。
